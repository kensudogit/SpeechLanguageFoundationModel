# 仮定と未確定事項

このデモは Skill の開発手順に沿ったローカル実行用です。実音声の認識精度や会話品質は測っていません。

| 番号 | 内容 | 状態 |
|---|---|---|
| OPEN-01 | 音声形式は wav / mp3 / webm / ogg。上限 10MB | 固定（デモ） |
| OPEN-02 | 既定言語は日本語。Whisper 接続時のみ `ASR_LANGUAGE` を使う | 固定（デモ） |
| OPEN-03 | 遅延・スループットは未計測 | 未計測 |
| OPEN-04 | `API_TOKEN` が空なら認証なし。入れると `X-Demo-Token` / `?token=` が必要。HTTPS とマルウェア検査は未実装 | デモ |
| OPEN-05 | 既定 ASR / LLM / TTS は mock。音声もテキストも外部へ送らない | 固定（デモ） |
| OPEN-06 | `ASR_PROVIDER=whisper` は任意。モデル取得にネットワークが必要 | 未接続 |
| OPEN-07 | `LLM_PROVIDER=openai` は文字起こし結果のテキスト応答だけ。音声ファイルは送らない | 任意 |
| OPEN-08 | TTS はモックの短い音。実音声合成ではない | 固定（デモ） |
| OPEN-09 | 履歴の保存期間は `RETENTION_HOURS`（既定 168）。期限切れは起動時と削除 API で消す | デモ |
| OPEN-10 | 音声データはモデル学習に使わない | 固定 |
| OPEN-11 | ホストの PostgreSQL 5432 は他プロセスが使用中のため、この Compose は **5440** | 固定（ローカル） |
| OPEN-12 | `/ws/live` は録音断片を受けて最後にまとめて文字起こしする。実時間の連続 ASR ではない | デモ |
| OPEN-13 | 回数制限はプロセス内メモリ。本番の分散制限ではない | デモ |
| OPEN-14 | 監査は操作名と成否だけ。音声・秘密鍵は残さない | デモ |
| OPEN-15 | HTTPS・マルウェア検査・ブラウザ自動 E2E・本番の分散レート制限は未実装 | 未実装 |
| OPEN-16 | `/metrics` と `scripts/load_smoke.py` は回数だけ。遅延の SLA ではない | デモ |
